# Проверка разнообразия тренировок — 16.09.2026

Проверены общий генератор `generate`, постановка в очередь `generate-async`,
завершение `generate-status`, загрузка истории и проверка результата.
Это проверка кода и автоматических сценариев, не серия платных генераций на
реальных игроках. Изменения требуют отдельной публикации для работы на сайте.

## Обнаружено

- История содержала шесть последних сохранённых сессий без отсечения по целевой
  дате. Будущие планы могли вытеснить нужные предыдущие тренировки.
- Ротация была рекомендацией в промпте. До 40% повторов аксессуаров проходили
  проверку, остальные теряли лишь 3 балла без автоматического исправления.
- Старый анализ текстовой истории учитывал только коды A–E, пропуская F.
- Любые A1/B1/C1 исключались из сравнения аксессуаров, в том числе в профилактике.
- Отдельное указание сохранять prehab 3–6 экспозиций противоречило разнообразию.

## Поведение по методам

| Методы | Правило ротации |
| --- | --- |
| Силовая/поддержание, накопление, силовая база | До двух основных якорей для прогрессии; остальные упражнения сравниваются с историей |
| Мощность/скорость, конверсия, перенос, взрыв | То же окно ротации; сохраняются режим, двигательные задачи и ограничения дозы |
| Профилактика, восстановление, deload, структурная подготовка | Проверяются все блоки; код A1/B1/C1 сам по себе не разрешает повтор |
| MD-1 активация, тейпер | Ротация в рамках короткого безопасного протокола без увеличения объёма |
| Сборы: эксцентрика и изометрия обеих цепей/full-body | До двух основных якорей; вспомогательные варианты меняются с сохранением метода и волны дозировки |
| Игровой праймер, реабилитация | Повторы анализируются, но не вызывают автоматической замены: ограниченная библиотека и назначенный протокол приоритетны |

Правила применяются ко всем пяти типам: передняя цепь, задняя цепь, всё тело,
восстановление/профилактика, активация/мощность. Метод и тип по-прежнему разрешаются
существующей логикой тренера/готовности; ротация не переключает метод.

## Новая проверка

История загружается до целевой даты, максимум 12 сохранённых программ одного
игрока в выбранном workspace. Для ротации берётся объединение двух последних
программ вообще и двух последних программ текущего метода в этом окне.
Проверяются упражнения всех блоков по структурированным данным. Частые английские
сокращения нормализуются; оборудование и реальные варианты сохраняют различие.
Это не семантическое распознавание любых русско-английских синонимов.

При повторах выполняется одна попытка исправления модели, общая с существующей
проверкой силовой методики в очереди. Кандидат не принимается, если ухудшил
пройденные проверки безопасности, дозы или структуры. При ошибке исправления
сохраняется исходный готовый результат. Неразрешённые повторы видны в качестве
программы и требуют просмотра тренером; сами по себе они не запрещают сохранение.

Контекст строится по сохранённым программам. Несохранённые черновики не создают
историю; при нескольких одновременных генерациях они ещё не видят результаты
друг друга. Гарантии полного отсутствия повторов модель не даёт: ограничения
игрока и безопасность важнее новизны.

Автотесты перебирают все методы из `FOCUS_LABELS` и все пять типов, проверяют
третье повторение подряд, блок F, ограничения якорей, будущие даты, границы
workspace, нормализацию названий и выбор безопасного исправления.
