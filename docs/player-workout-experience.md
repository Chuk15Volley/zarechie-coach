# Выполнение тренировки игроком

## Изменения

- Пары и тройки: порядок подходов по кругам, подсказка следующего задания, отдельный отдых для явно указанных переходов и завершения круга. Для неоднозначного свободного текста сохранён резервный расчёт по максимальному интервалу; диапазон использует верхнюю границу.
- Таймер считает время до заданного момента, восстанавливается после перезагрузки и возвращения из фона. Пауза также сохраняется. Работа уведомлений при заблокированном экране не гарантируется браузером.
- Завершение раньше: причина, сохранение фактически выполненного, возможность продолжить. Тренер видит отдельный статус и причину; невыполненные подходы не засчитываются.
- Вес вводится отдельно от отметки подхода. Плановый или предыдущий вес применяется только явным нажатием. Есть переход к пропущенному весу.
- Черновик оценки сохраняется локально. После нажатия отправки неудачная попытка повторяется при восстановлении сети, возвращении в окно и каждые 15 секунд, пока страница открыта. При повторном открытии очередь восстанавливается. Клиентские ошибки требуют исправления и повторной отправки.
- Подтверждение получения оценки записывается после сохранения фактического выполнения. В историю реакции на упражнения попадают только выполненные упражнения.
- История показывает выполненные подходы, записанный вес, длительность, RPE, комментарий и причину завершения. Записи фактического выполнения служат резервом после истечения срока хранения оперативного лога.
- Тоннаж использует подтверждённые веса; секунды удержаний не считаются повторениями. Односторонние повторения учитываются одинаково в интерфейсе и API.

## Проверка

- 407 тестов из репозитория и новых тестовых файлов.
- Изолированный браузерный сценарий на синтетическом игроке: 15 секунд A1→A2, 180 секунд после пары; перезагрузка таймера; сохранение паузы; завершение 2 из 4 подходов; восстановление черновика RPE; отправка; просмотр факта в истории.
- Тесты очередей: медленный ответ не удаляет новую правку; отправка сохранённой очереди при открытии; повтор после 503; восстановление сети; изменение факта требует обновлённой оценки.
- Тесты API с изолированным хранилищем: частичная тренировка, разделение workspace, ошибки чтения и записи без ложного успешного подтверждения.
- Реальные тренировки в проверках не запускались и не изменялись.
