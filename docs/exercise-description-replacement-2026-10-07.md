# Автоматическое описание при замене упражнения · 2026-10-07

В открытой программе Jelena Mladjenovic на 8 октября название A1 было Goblet Squat ISO, но cue и compactDescription оставались от Supine Heel Slide. То же произошло у C1 и D1. Выбор из библиотеки, альтернативы и ручной ввод использовали обработчик, менявший только name/exerciseId и сбрасывавший descriptionOverride. Рендер продолжал отдавать приоритет старому compactDescription.

Общий обработчик смены названия теперь очищает все унаследованные поля техники и создаёт описание нового движения локально. Дозировка и остальные назначения не меняются. descriptionExerciseId связывает описание с упражнением; общий рендер и нормализация при сохранении исправляют несовпадение. Сервер сохранения дополнительно сравнивает упражнение с сохранённой версией для вкладок старого клиента, сохраняя новое авторское описание тренера или новую технику модели. Кнопка перегенерации возвращает отдельное новое упражнение и проходит ту же нормализацию.

Механизм общий для обоих пространств и всех методик. Упражнения без распознанного двигательного шаблона получают новое общее описание с названием и предложением сверить технику по видео/с тренером; техника неизвестного движения не выдумывается. Проверенные поля описания тренера сохраняются до следующей смены упражнения.

Проверки: 607 тестов прошли, один пропущен; production build успешен. Регрессии покрывают исходный случай, смену разных семейств, старый клиент, сохранение нового текста тренера/модели, нормализацию, восстановление и общий рендер игрока.
