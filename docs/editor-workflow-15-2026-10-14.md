# Быстрая коррекция: 15 улучшений

Общий редактор Заречья и NK Pro. Исходная публикация 1668066; изменения касаются интерфейса, локального восстановления и проверки формата плановых полей. Генерация метода, дозировка, ReadySix, медицинские ограничения, запреты, циклы и исходные результаты не изменены.

1. Рабочая копия session автоматически записывается только в localStorage текущего сайта, на 7 дней. Ключ включает пространство, игрока, день, queue/job; восстановление явное, только при совпадении полного основания серверной версии. Изменившийся серверный черновик не перезаписывается старой копией. Никаких автоматических server save/publication.
2. Проверка подсказок отмечает резкие указания для подвижности, отсутствие приземления и противоречащие паузы. Сохранённый текст не переписывается.
3. Ориентиры учитывают одноногую румынскую тягу и половину коленного положения для мобилизации; точный reviewed вариант из каталога используется при ручной замене. «Использовать этот ориентир» — явное действие тренера.
4. RPE из старого комментария виден рядом с полем, источник обозначен. Конфликт с полем отмечен; только намеренная правка корректного RPE синхронизирует существующую текстовую RPE, сохраняя медицинские комментарии.
5. Некорректный RPE/вес/пустые задания отмечаются с переходом к полю; выдача программы блокируется. API дополнительно отклоняет явно некорректные числовые кг/RPE. Существующие completed/alias/CAS/idempotence проверки сохранены.
6. Значение и единица повторов/времени/дистанции разделены. Число «всем» сохраняет исходную единицу каждого подхода; изменение единицы отдельно явно. Произвольные форматы поддерживаются.
7. Таблица всех упражнений по умолчанию; выбранная строка открывает рядом видео, технику, замену и подходы. «Все карточки» сохраняет прежний подробный режим; print/read-only не фильтруются выбором строки.
8. «Сохранить и следующий» использует прежнее guarded program save и переходит только после успеха; последний игрок может перейти к оставшимся предыдущим.
9. До 20 последних состояний упражнения доступны через «Отменить», включая замену, кг/RPE, массовые повторы и удаление подхода. История фактов не изменяется.
10. Русские синонимы, сокращения и одна небольшая опечатка/перестановка букв участвуют только в поиске.
11. В выдаче видны инвентарь/опора/сторона/хват/удержание и похожие названия; исходные canonical IDs и история не объединяются.
12. Перед выбором видны сохраняемые подходы/темп, сбрасываемые кг/прогрессия и изменение задачи. Техника сравнивается по желанию, без обязательного дополнительного подтверждения.
13. Избранные/недавние доступны в быстром подборе; общий каталог кэшируется в памяти на 5 минут, ошибки можно явно повторить. Запреты и индивидуальные ограничения фильтруются при каждом открытии.
14. Новая YouTube-ссылка показывает предпросмотр до записи. Область сохранения явно общая для точного упражнения в обоих пространствах; отмена ссылки не записывает её. Один миниплеер можно закрепить поверх прокрутки; он порталируется внутрь native dialog, сохраняет top-layer доступность. Ошибка оставляет ссылку, повтор повторяет именно сохранение.
15. Устаревшая подсказка прогрессии предлагает проверку текущего упражнения/нагрузки, не перегенерацию всей программы. Критерии применимости и запрет переноса кг неизменны.
