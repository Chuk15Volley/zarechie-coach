# Рабочий экран игрока в зале

Стартовая страница показывает короткое название, объём и кнопку старта. Дата и настройка экрана находятся в раскрываемом разделе. Статус офлайн-копии остаётся видимым и не обещает доступность видео без сети.

Во время выполнения обычный блок показывает первое незавершённое упражнение; пары и круги остаются вместе. Переключатель открывает всю программу, включая завершённые и пропущенные упражнения. Подход раскрывает поля фактического веса и повторений до подтверждения. Игрок может использовать план или вес предыдущего подхода. Значения по плану становятся фактом только после явного подтверждения подхода. Повторы вводятся для однозначных числовых назначений, включая «на сторону»; временные и сложные составные задания не превращаются в повторы.

Фактические повторения и их временные метки проходят через локальную очередь, восстановление после перезагрузки, серверное объединение, итоговую оценку и историю. Старые записи без фактических повторений сохраняют прежнее поведение. Пропуски не считаются выполненными. Значения для каждого упражнения на сторону учитываются в тоннаже обеих сторон ровно один раз.

Названия упражнений показываются в исходном виде, как сохранены тренером, включая английские названия. Идентификаторы не меняются, поэтому поиск видео и история продолжают работать. Интерфейс и подсказки остаются на русском. Рекомендации по технике сохраняются целиком в раскрываемом разделе; рядом с подходом показывается короткая подсказка.

Видео продолжает открываться по исходной ссылке: ранее встроенный проигрыватель вызывал проблемы доступа. Автоматических замен упражнений нет; при занятом оборудовании игрок может пропустить упражнение, указать причину и вернуться к нему через всю программу. Замену определяет тренер.

Проверено на локальной синтетической программе в мобильном окне 390×844: старт, изменение повторений, восстановление страницы, ввод веса, перенос веса предыдущего подхода, переход между упражнениями, таймер отдыха, пропуск и отображение пары. Реальные результаты игроков при проверке не изменялись.

### Athlete visual system and preparation countdown

The athlete UI shares the coach workspace visual language: dark translucent panels, emerald/cyan accents, Prata display headings and Manrope controls. Block colors repeat consistently across navigation, preview and exercise badges (A blue, B violet, C mint, D orange, E pink, F cyan, then repeat). Letter labels, the current-step outline and completion marks remain visible independently of color.

Rest and hold timers share a 76px circular dial, tabular digits and equal-width action grids. A hold starts with five seconds of preparation before the full prescribed work duration; each additional side receives the same preparation period. Pausing and restoring preserves preparation separately from work, including fractional seconds. Existing timers without preparation metadata remain compatible. Rest timers start immediately.


### Голос таймера

Голос включён по умолчанию; переключатель до старта и в рабочей панели сохраняет выбор на устройстве. «Проверить звук» позволяет проверить громкость до упражнения. Нажатие старта активирует речь через пользовательское действие. Удержания озвучивают «Подготовься к подходу», «Начинай», «Удержание завершено», отдых — «Начинай следующий подход». Названия игроков и упражнений в синтез речи не передаются.

Команды произносятся только для наблюдаемого перехода в открытой странице. Восстановление, пропуск, отмена и запоздалое возвращение из фона не запускают старые команды. Выключение звука и уход со страницы останавливают текущую речь. При ошибке движка доступна повторная проверка; отсутствие поддержки речи не блокирует таймер. Звук при блокировке телефона или в фоновой вкладке не гарантируется.

Используется встроенный [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis), с предпочтением локального русского голоса из [getVoices](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices). Проверки переходов, отключения, восстановления и ошибок входят в тесты синхронизации игрока.


Основная озвучка — пять заранее созданных OpenAI gpt-4o-mini-tts / cedar команд спокойным мужским голосом (17.09.2026), WAV 24 кГц. Файлы `/audio/timer-voice-v1/` воспроизводятся через Web Audio и кэшируются как статические ресурсы для повторного использования. Убрана тишина по краям с запасом 30 мс. Интерфейс сообщает, что голос создан ИИ. API-ключ не поставляется в браузер, генерация при тренировке не требуется. Встроенный русский синтез остаётся резервом при недоступности записи. Ожидающий разблокировки звук отменяется вместе с таймером; опоздавшие команды не проигрываются.
