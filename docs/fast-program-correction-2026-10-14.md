## Редактор

- Плановые кг, RPE, повторения каждого подхода и добавление/удаление подходов видны сразу. «Применить всем» заполняет выбранный текст во всех существующих подходах, сохраняя их количество и форматы `/side`, секунд и дистанций. Медицинские/методические ограничения и сохранение остаются прежними.
- Для гантелей/гирь — прямые кнопки 1/2 внутри dialog, вес всегда одного снаряда; строка показывает кг × количество. Старый PremiumSelect выводил меню за пределы native dialog. Другие списки теперь портируются внутрь открытого dialog и ограничиваются его фактическими границами; Escape закрывает меню, не карточку.
- Смена количества снарядов снимает несовместимый снимок рабочего веса (`loadEvidence`/`loadProgression`), не переносит кг и не меняет фактические данные.
- Дробный вес принимает запятую. Очистка удаляет старые кг из комментария, чтобы legacy fallback не возвращал их в поле. Изменение веса сохраняет остальные указания комментария, включая RPE и предупреждения.
- «Заменить» открывает компактный поиск с фокусом, без полного атласа. Поиск по всему доступному каталогу, фильтр движения; отдельная кнопка выбирает вариант одним нажатием, техника просматривается по желанию. Прежние запреты/ограничения, сброс кг и причина замены сохранены. Автоматический подбор обозначен отдельно.
- Ссылка видео доступна сразу под плеером: вставить и Enter/«Сохранить видео». Сохранение по-прежнему отдельное, в общей библиотеке точного упражнения. Ошибки не стирают ссылку, успех объявляется только после ответа API. Ручной поиск YouTube — только по нажатию ссылки, автоматического поиска нет.
- Видео раскрыто, но компактно: 150 px на компьютере, 130 px на телефоне; отдельное увеличение 300/230 px. Нет автозапуска при открытии карточки. Пустой видеоблок 55 px. Редактор получил больше ширины, обзор уплотнён, проверки/история нагрузки раскрываются отдельно. Исходные медицинские предупреждения остаются доступными в обосновании и карточках.
